# NEWS

## Version 3.1.0

Minor release reducing the default Stieltjes convergence tolerance from `1.0e-15` to `1.0e-17`, while streamlining expensive Stieltjes tests.

## Version 3.0.5

Patch release with non-breaking interface cleanup, updated Stieltjes output naming with compatibility aliases, and aligned documentation/examples.

## Version 3.0.0

Major release with breaking interface changes, a revised weight-function specification, refactored Stieltjes workflows, and broader testing/documentation updates.
